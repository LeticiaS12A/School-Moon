School Moon 🌙

---

1. Sobre o Projeto
O School Moon é uma plataforma web de ensino gratuito voltada para iniciantes em Análise e Desenvolvimento de Sistemas (ADS).
O objetivo é oferecer conteúdos organizados de forma progressiva, facilitando o aprendizado contínuo.

---

2. Funcionalidades
- Cadastro e login de usuários (JWT)
- Visualização de cursos
- Dashboard com progresso do aluno
- API REST com Node.js
- Integração com banco de dados MySQL

---

3. Tecnologias Utilizadas
- Node.js
- Express
- MySQL
- JavaScript
- HTML/CSS
- Chart.js

4. Como Executar o Projeto

---

1. Instale as dependências:
npm install

2. Configure o banco de dados:
- Execute o script.sql no MySQL
- Ajuste usuário e senha no arquivo config.js

3. Inicie o servidor:
node src/app.js

4. Acesse no navegador:
http://localhost:3000
